Open the plotting window on your Mac

Create your handwriting on any supported device, then download its G-code and transfer the file to the Mac connected to the plotter.

  1. In the Handwriting Studio folder on that Mac, double-click Start Plotter.command.
  2. The local plotting window opens. Choose your G-code file and inspect the A4 preview.
  3. Connect the idle plotter, use Home, prepare the paper and start the drawing.

Once the launcher is running on this Mac, open the local plotting window. This address works only on the connected Mac; it will not launch the window from an iPad.

First-time setup or missing launcher? See Mac plotting setup.
