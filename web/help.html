Getting started

The public app runs in Safari or Chrome, including on an iPad. You do not need to start the Mac app or sign in. Writing is saved in this browser on this device; it is not uploaded to GitHub or automatically shared between devices.

  1. Capture a set using the same writer name for the same person. Repeat sets to collect variations.
  2. Review samples to check characters, exclude poor examples or adjust their size and baseline.
  3. Blend a character to mix two or four captures and save a new version.
  4. My alphabet shows coverage and lets you choose preferred versions.
  5. Compose creates an A4 preview and downloads SVG or plotter G-code.
  6. Use Backup / Import regularly to keep a copy of your saved work.

Capture letters and other characters

  1. Enter a writer name and tap Done. Choose Lowercase, Uppercase, Numbers, Punctuation and symbols, or Joined pairs.
  2. Practice is optional and is not added to your alphabet; unfinished practice can have a recovery copy. Tap Start capture to open the next unsaved sheet for that writer and capture type.
  3. Write the labelled character inside each box using a Pencil or mouse. Keep every stroke, including dots, in its own box. Fingers operate controls but do not draw on the capture sheet.
  4. Tap Save sheet and wait for confirmation. The next sheet opens only after a successful save. Undo, Redo and Clear sheet affect the current draft.
  5. At the end of the set, review or compose, or choose Capture another set. Two complete sets give two originals per character; four give four.

Each set shuffles its characters. Lowercase has six sheets covering all 26 letters; other groups show their own sheet count. Capture types keep separate progress. Finish the current set before changing type. The writer is fixed during capture; to change writer, save the sheet and reopen Capture.

Keep small letters around the small-letter guide and capitals around the tall-letter guide. For f, g, j, p, q and y, place the body on the baseline and the tail below it. Other lowercase letters settle onto the baseline automatically. Capitals, numbers, punctuation and joined pairs retain their drawn baseline. Write a joined pair as one connected shape.

The five guide checkboxes control Baseline, Small letters, Tall letters, Tails and Shading. Labels and box dividers remain visible. Gentle smoothing changes the displayed and exported line without changing original strokes. Saved progress resumes after reopening. If an unfinished recovery copy is available, choose Restore draft to return to its original shuffled labels and strokes.

Review samples

Choose the writer, group and character, then an individual example from the newest-first list. Both original captures and saved blends can be reviewed; blends are labelled.

  • Use this sample in composition includes or excludes that example. Excluded originals are also unavailable as blending sources. Excluding keeps the sample and can be reversed.
  • The vertical Position slider is beside the preview: slide up to raise the letter or down to lower it, by up to 10 mm. The readout shows the distance and direction. The preview moves immediately against fixed guides at Medium (5 mm), with the complete letter centred horizontally. Original baseline returns to zero offset; save to keep that position. Arrow keys adjust by 0.1 mm, or 1 mm with Shift. Preview centring does not change the saved writing or composition spacing.
  • Letter size scales height and width together from 50% to 200%, around the original baseline. Original size returns to 100%. The letter changes live. Try a short word compares your pending adjustment with other saved letters at Medium (5 mm); edit the word if it needs missing characters. The word preview includes this sample even if excluded, and does not save changes.
  • Preview size enlarges only the display, from 100% to 300%. Colour separate strokes starts on; Show numbered stroke starts optionally marks where each stroke begins. These display tools do not change the saved letter or exports.
  • Save changes stores inclusion, size, position and stroke corrections. Reset changes restores all saved settings. Save or reset before switching samples.

Saved size adjustments are used in My alphabet, new blends, proof sheets and Compose. Original strokes are kept: return Letter size to 100% to restore their original size. This is a manual adjustment that preserves proportions, not automatic equalisation of heights. Baseline adjustments apply at the same physical distance for each Compose writing size. Generate a new Compose preview after reviewing. Changes to an original do not remake an already saved blend; create a new blend if you want it to use different source adjustments.

Correct stroke order and direction

Select a stroke under Correct stroke order and direction. Use Move earlier, Move later or Reverse direction. Colours identify the current sequence and numbered markers show where strokes start. The preview updates immediately. For example, put the body of “t” before its crossbar in both source samples.

Undo stroke change steps back through up to 50 adjustments in this review. Original order and directions restores the sample’s original sequence. Use Save changes to keep corrections or Reset changes to discard the pending review. Saved corrections apply to this sample in new blends and writing; original points, timing and sensor data are preserved.

After correcting source samples, return to Blend a character and tap Refresh originals. Existing saved blends and finished drawings keep their original appearance. This tool does not add, delete or join strokes: different stroke counts or very different shapes still require other sources or new captures.

Blend a character

Blend several captures of the same character. For example, blend two versions of “a”, or four versions of “a”.

  1. Choose Save under writer, the character and Two or Four sources.
  2. If your sets were saved under different writer names, choose Source pool → All saved writers / sets. Each source choice shows its writer, date and sample identifier. This does not merge or rename writers.
  3. The app looks for compatible originals when you change character, source pool or source count. You can select a different original in each source box. Selecting one already used in another box swaps those selections. Saved blends cannot be selected as source originals.
  4. Drag the green-bordered blended character towards a source to make it more like that source. Its shape updates continuously. With two sources, move left and right between A and B. With four, move in any direction between A/B above and C/D below.
  5. Tap Save blended sample to save the displayed result under the chosen writer. It is then available in Review, My alphabet and Compose. Original captures are kept.

After saving, the confirmation panel shows the character, writer and preview. Use as preferred adds it to that writer’s preferred choices, keeping any other selections. View saved blend opens My alphabet with the saved sample highlighted. Blend next character moves to the next character in the list and restores an equal mix; save first to keep your current result.

Choose a Saved version and tap Reopen source mix to restore its original sources, stored sizes, baseline adjustments, stroke corrections and blend position. Older blends restore their original source sizes and uncorrected stroke order. You can also reopen from the sample’s card in My alphabet. Adjusting and saving creates a new version. Later Review adjustments on the saved blend stay with that old sample. If an original source is excluded, include it in Review before reopening. Changing the source selections uses their current Review adjustments.

The draggable result has a transparent background, so source letters remain visible underneath it. Use a finger, Pencil or mouse. Scroll the page from outside the draggable character. Centre blend restores an equal mix: 50% each for two sources, or 25% each for four. At a source position, that source contributes 100%.

Show guides is off by default. Preview size enlarges the display from 100% to 200%; swipe sideways outside the draggable result to inspect an enlarged preview. These display controls do not change the saved blend. With the result focused, arrow keys adjust the mix by 1%; Shift + arrow keys adjust it by 10%. Up/down apply to four-source blending.

Colour separate strokes shows the first stroke dark, the second blue, and later strokes in other colours. Show numbered stroke starts adds current stroke-order numbers where each stroke begins, including on the moving result. Use these to compare dots and crossbars. They do not reorder strokes or change exported ink.

Normalisation and compatible samples

The app aligns source left edges and baselines, then compares 64 evenly spaced points along each stroke. It retains your relative letter sizes rather than forcing every letter to the same height. Sources need matching stroke counts, order and direction, and sufficiently similar shapes. For a dotted letter, make the body and dot in the same order in each capture. The comparison allows natural size and dot-position differences relative to letter height and width. If your choices cannot be blended, the message names the conflicting sources and explains why. Tap Find compatible sources to search for another pair or quartet in this pool, favouring your current choices. Manual source changes are kept until you request a search or change character, pool or source count. Reopening a saved mix preserves its exact sources. If no set is found, try two sources, another source pool or capture more examples; searches of very large libraries are limited to keep the page responsive. If stroke order or direction differs, correct the originals in Review, save, then Refresh originals here. Inspect the result before saving.

My alphabet and preferred versions

Choose a writer and group to see which characters have included originals, saved blends and preferred versions. The summary lists missing samples and characters without a saved blend.

Select a character, compare its samples, and tap Add to preferred on one or more included originals or blends. Remove from preferred removes just that choice; Clear preferred choices returns that character to normal selection. Choices save immediately, in the order added, and belong to the selected writer. Existing single preferences are kept. An excluded preferred sample is shown as unavailable and is not used.

Preview size enlarges the alphabet tiles and sample cards from 100% to 300%. Reset size returns to 100%. These display controls stay at the top while you scroll. Previews leave less empty space around the ink and keep a shared scale within each comparison.

Colour separate strokes starts on: the first pen stroke is dark, the second blue, and later strokes use other colours, repeating after six. A “t” crossbar is blue if you lift the pen and draw it as the second stroke. A dot is also a separate stroke when drawn after lifting the pen. Untick the checkbox for a single ink colour. These are display settings only; saved handwriting, preferred choices and exported writing size and colour stay unchanged.

In Compose, Use preferred versions when available is enabled by default. In sequence mode cycles through your included preferred choices in the order added; shuffled mode varies their selection, provided they match the selected source type. One eligible choice is reused each time. If none qualify, Compose uses the allowed sample pool. Turn the option off to use that pool instead. The Latest three/four/only setting does not limit preferred choices.

Individual character spacing

In My alphabet, select a character and find Spacing for…. Adjust Before the character and After the character between −2 and +3 mm. These values refer to Medium (5 mm) and scale with writing size. Negative values tighten gaps; positive values add space. Tight settings may overlap ink.

Try a short word shows the change live using your preferred versions or normal samples. Save spacing applies it to all versions of that character for this writer. Normal spacing returns both values to zero; save to keep it. Reset changes restores the saved values. Save or reset before switching characters. Arrow keys adjust by 0.1 mm, or 0.5 mm with Shift.

Letter shapes and blend sources stay unchanged. Joined pairs have their own settings; individual-letter spacing does not apply inside a joined pair. Generate a new Compose preview to see saved spacing changes. Older finished drawings stay unchanged.

Alphabet proof sheet

In My alphabet, tap Alphabet proof sheet to test the selected writer and group. Choose originals, saved blends or both, and Small (3 mm), Medium (5 mm) or Large (8 mm). Included preferred versions cycle when the source type permits them; otherwise the newest included sample is used.

The available characters appear in group order, followed by an optional test sentence. Missing group characters are listed and omitted from the character row. Missing characters in your test sentence prevent export: capture them, change the source type, edit the sentence or leave it blank. The initial example uses available writing; your edited text is kept when changing settings.

Test sentences offers eight pangrams, each containing all 26 lowercase letters: The quick brown fox, Pack my box, Sphinx of black quartz, How vexingly quick, The five boxing wizards, Bright vixens, Waltz bad nymph and Jackdaws love. Choose one, or All eight pangrams to try them together. Choosing an example replaces the text. You can edit it, choose Your own text to keep editing the current text, or restore the Automatic example.

For a block of writing, choose Sheet → Text passage. This leaves out the alphabet row and uses the selected writer, source type, writing size, preferred versions and Review adjustments. The examples include Sonnet 18 by William Shakespeare: Lowercase letters only omits punctuation and works with a lowercase alphabet; Original text also needs saved capitals and punctuation. Both keep all fourteen verse lines. Choosing a passage example opens Text passage automatically. You can also paste your own text.

Alphabet sheets and passages keep explicit line breaks, wrap long lines at word boundaries and continue onto further A4 pages as needed. The limit is 10,000 characters including the alphabet row, and 20 pages. Use Previous page and Next page to inspect the whole document. The preview updates as you edit; Refresh preview reloads saved choices too.

Natural variation → Off / Subtle / More pronounced adds small changes to word gaps, letter sizes and the slope and curve of lines. It updates live and keeps margins clear. Try another natural variation picks a new pattern; refreshing, switching pages or changing the amount keeps the current pattern while this page is open. Use Off to inspect your unaltered samples. Download a proof to keep its exact appearance; proof settings are not saved on closing the page. Compare versions always uses its fixed comparison layout. See Natural variation for the amounts and how to save a composition.

Downloads contain exactly the displayed page. Single-page alphabet sheets use alphabet-proof-a4.svg or alphabet-proof-a4.gcode; passages use text-proof-a4.svg or text-proof-a4.gcode. With several pages, the download buttons say Download this page and filenames add -page-1, -page-2, and so on. Download each page separately. Downloads are disabled while updating or if samples are missing, a word is too wide or a document exceeds the limits.

The typed text box is for editing. Look at the Handwriting preview below to see your writing and its variations. The toolbar above it keeps Preview zoom and Natural variation together and shows the active amount. Choose 200% or 300% and switch between Off and More pronounced to inspect small changes. Scroll or swipe inside the preview to inspect enlarged areas. Zoom ranges from Fit page width to 400% and stays selected when settings or pages change. It changes only the display; your writing size, variation pattern and exported drawing stay the same.

Exports use the selected physical size on A4 with 20 mm margins. Print SVG at 100% without fit-to-page. Send G-code from the connected Mac using the verified calibration procedure.

Compare versions on paper

Choose Compare versions in My alphabet, or Sheet → Compare versions on the proof screen. The A4 sheet has three columns: your latest included originals, latest included saved blends, and included preferred choices. Every test appears at 3, 5 and 8 mm. Preferences cycle in their saved order and restart at each size.

The suggested text tests f, i, j, l, t and z using individual letters, “fizz” and “jilt”. Enter other characters or short words if preferred, up to six lines and 120 characters. Current Review adjustments and character spacing apply. Joined pairs are not substituted in this comparison.

Crossed boxes mark missing versions, with the missing characters listed beneath the controls. Existing letters remain visible. The preferred column needs explicit choices in My alphabet; no other version is substituted. If a word or the page does not fit, shorten the text.

Column labels, size labels and missing markers are drawn in both exports. Downloads are comparison-proof-a4.svg and comparison-proof-a4.gcode. Export uses physical sizes on A4 with the verified calibration and 20 mm margins. Send G-code from the connected Mac after preparing the plotter.

Compose and export

  1. Choose a writer and enter text using characters you have captured. Capitals, digits, supported punctuation, spaces and line breaks are allowed. The initial example uses available characters; your edited text is preserved when settings change.
  2. Choose Original samples only, Saved blends only, or Originals and saved blends. The default includes both. Saved blends only reports missing blends instead of substituting originals.
  3. Choose the sample pool: Latest three per letter (default), Latest four per character, Latest only, or All saved. Eligible preferred versions take priority; otherwise Compose uses this pool. Choose In sequence or Shuffled under Sample order.
  4. Choose Small (3 mm), Medium (5 mm) or Large (8 mm). These sizes refer to the small-letter guide and preserve your natural proportions. Set Gentle smoothing and Use saved joined pairs as desired.
  5. Tap Generate preview, inspect the result, then choose Download A4 SVG or Download plotter G-code. Look in your browser’s Downloads.

When enabled, saved joined pairs replace matching character pairs where available; otherwise individual letters are used. Pair samples follow the same source, inclusion and preferred-version rules. The supported pairs are th, he, in, er, an, re, on, at, en, nd, oo, fi, of and tt. This does not automatically join all letters into cursive.

Pages are A4 portrait (210 × 297 mm). Whole words wrap together and continue onto a new page when needed, up to 10,000 characters and 20 pages. If a word is too wide, use smaller writing, narrower margins or add a space. Split longer documents; text is never silently clipped.

Letter spacing, Word spacing and Line gap adjust from 50% to 200%. At 100% they use the normal layout. Letter spacing changes the distance between character starts, word spacing changes the space between words, and line gap changes the clearance between lines. Character size and shape stay the same. Tight spacing can overlap letters. Reset spacing returns all three to 100%.

After Generate preview, spacing, page-layout and natural-variation controls update all pages live. The previous image stays visible while updating; both downloads remain disabled until the new result is ready. Wider spacing can add pages. If a word cannot fit or the document exceeds 20 pages, reduce spacing, use smaller writing or shorten the text. Other settings still require Generate preview. Spacing settings do not change saved samples and can be kept in a saved composition.

Natural variation

Choose Off (the default), Subtle or More pronounced. Subtle varies word gaps by up to ±5% and letter sizes by up to ±1.5%; More pronounced uses up to ±10% and ±3%. Dots, crossbars and joined-pair samples scale together with the rest of their character around its reviewed baseline. Nearby sizes and gaps change gradually.

Lines share a slight overall slope with gentle differences between lines: up to ±0.15° slope and ±0.15 mm curve for Subtle, or ±0.35° and ±0.35 mm for More pronounced. The layout leaves extra vertical room for the drift, keeping writing inside the selected margins and keeping lines apart. This can add pages. Your stored samples and Review settings remain unchanged.

After Generate preview, changing the amount updates all pages live. The pattern remains fixed as you adjust amount, spacing or layout, or generate again, for unchanged text and samples. Try another natural variation chooses a new pattern without changing the selected letter samples. It works even when a character has only one saved version. Sample order controls which versions are selected separately.

Save composition keeps the amount and pattern; generate before saving to keep all finished pages exactly. Draft recovery and Backup / Import also retain the pattern. Older compositions open with Off. SVG and G-code reproduce the displayed geometry. Proof sheets offer natural variation for alphabet sheets and passages too.

Margins, alignment and paragraphs

Under Page layout, set top, bottom, left and right margins independently from 20 to 60 mm. The minimum keeps writing inside the verified plotting area. Choose Left, Centre or Right alignment for each line within those margins.

Leave a blank line between paragraphs. Extra paragraph gap adds 0–30 mm after the blank line; an ordinary single line break has no extra gap. Reset page layout restores 20 mm margins, left alignment and zero extra gap. Leading/trailing blank lines do not create empty pages, and blank space crossing a page break is discarded. Letter choices continue across pages without restarting.

Preview and download each page

Use Previous page, the Preview page list or Next page above the image. Both download buttons export only the selected page. Download each page separately. A document with several pages uses numbered names such as composed-handwriting-a4-page-02-of-03.svg and composed-handwriting-a4-page-02-of-03.gcode. Single-page filenames remain unchanged.

Finish plotting one file, then fit fresh A4 paper at the same top-left home before sending the next file. Each file raises the pen before travelling and returns home when finished. The website does not send files or feed paper automatically.

Shuffle letter versions

Sample order → In sequence keeps the usual cycle. Choose Shuffled · avoid repetition to use every eligible version once per shuffled round, avoiding the same version on consecutive occurrences of that character when alternatives exist. Your inclusion, source, preferred-version and sample-pool settings still apply, including to joined pairs.

Try another variation generates a new selection. Changing spacing, margins or alignment, or generating again, keeps the current selection for unchanged text and samples. Save the composition to keep the variation; generate before saving to preserve its exact drawing too. Older compositions open with In sequence. A character with only one version stays the same; two versions must alternate to avoid repetition.

Save and reopen a composition

Give your document a name under Saved compositions, then tap Save composition. It saves the text, writer, writing size, smoothing, source and sample choices, preferred-version and joined-pair options and all spacing and page-layout settings in this browser. Save updates the current composition; Save a copy creates a separate version. You can save a draft before generating a preview.

Generate preview before saving to keep every finished page exactly. The list shows Finished drawing, Finished document · N pages or Draft. Open a finished document to restore all its pages, with SVG and G-code downloads ready. It stays unchanged when your handwriting, reviews, preferences or character spacing change, and can reopen even without its original handwriting library. Browsing pages does not count as an edit.

Generate preview uses your current handwriting and settings instead. Editing text or layout invalidates old output; live updates keep the previous image visible while rebuilding. Generate again before updating a finished document; alternatively, Save a copy keeps the new settings as a separate draft and preserves the earlier drawing. Older settings-only compositions and finished single-page drawings remain supported. Backups include all saved pages. A saved composition has an 8 MB limit; if a very detailed document exceeds it, export its pages and save shorter compositions.

Each pen stroke exports as its own line path. Changes to text, settings, saved samples, review choices, character spacing or preferences invalidate fresh previews; generate again before downloading. Reopened finished drawings remain available until you edit the composition or generate a new preview. G-code uses the same preview and the verified calibration described below. The website downloads files; sending them to the plotter is a separate step.

Recover unfinished work

Capture, Free writing and Compose keep local recovery copies. Completed strokes are copied after the pen lifts; text and settings are copied shortly after edits. Look for Recovery copy saved on this device in the banner. An unfinished stroke is not copied. If storage fails, the banner tells you; use the normal Save button before leaving.

  1. Reopen the screen. If recovery copies are available, the recovery window opens. You can also tap Drafts.
  2. Choose a dated draft and tap Restore draft. Discard draft removes only that recovery copy after confirmation; Keep for later leaves it available.
  3. Continue working, then use Save sheet, Save page or Save composition. Restore and save drafts before downloading a backup.

Capture restores the writer, capture type, exact shuffled labels, sheet number, guides, strokes and Undo/Redo history. Free writing restores strokes, Undo/Redo and smoothing. Restored practice remains practice and is cleared when you start capture.

Compose restores text, title, writing and page settings, and the chosen variation, including partially entered fields. Generate a fresh preview before downloading. Saving a recovered composition creates a separate record so an earlier finished document stays intact. Exact preview pages belong to saved compositions and are not stored in recovery copies.

Clearing the current writing or saving it normally clears that working recovery copy. Restoring while another draft is on screen keeps the current work as a separate copy. Tabs keep separate copies; a listed draft may still be open elsewhere. Newer changes are kept.

Recovery stays in this browser and is not included in backups or synced between devices. An abrupt shutdown can lose the last edits, and clearing website data removes recovery copies. Continue to use Save and Backup / Import. Review and blending edits still need their own Save buttons.

Backup and import

Writing belongs to the browser and device where you saved it. Switching browser or device does not transfer it. Clearing website data or using private browsing can remove it.

  1. Save your current sheet, free-writing page or composition. Unsaved drafts are not included in a backup.
  2. Open Backup / Import and choose Download backup. Keep the JSON file somewhere safe. Check that it is in Downloads or your chosen folder, then tap I have saved the backup file.
  3. To move devices, transfer the JSON file, open this website in the destination browser, choose the file under Backup / Import and tap Import backup.
  4. After import, refresh the sample list or reopen Capture to see the writing. Reopen Compose to reload its saved-composition list.

Backup needed / Import highlights saved work that differs from the last confirmed backup. This includes edits to existing reviews, preferences, spacing and compositions. The count is saved items, not individual letters. Opening Backup / Import shows the last confirmation time.

A download request alone does not clear the reminder, because the browser cannot tell the app whether you kept the file. Confirmation covers the downloaded snapshot: anything saved afterwards still needs another backup. Older downloads are not automatically confirmed, and importing does not confirm a backup of the combined library. Recovery copies are separate; restore and save them first.

Backups include original captures, saved blends and their sources, review size/position settings and stroke corrections, preferred choices, character spacing, saved compositions with finished drawings and free-writing pages. Import validates the whole backup before adding anything. Identical records are skipped. A conflicting version of an existing record rejects the whole import without overwriting work. Keep both backups and use a separate browser/profile with no Studio data to inspect the other version; do not clear your current writing to solve a conflict. The file limit is 100 MB.

Calibration and sending to the plotter

The A4 procedure was physically verified on 8 October 2026. Home is at the paper’s top-left corner: positive X goes right and negative Y goes down. Pen up is Z0.5; pen down is Z5. Drawing speed is 900 mm/min.

  1. Place A4 portrait paper on the bed, home the plotter at its top-left corner and raise the pen.
  2. On Calibration, download and run Shapes with pen up to check movement.
  3. Run Pen down, then up; this stage has no X/Y movement.
  4. Run Draw shapes, Add dimensions and Mark page centre on the same fixed sheet. Alternatively, after the movement and pen checks, download the combined drawing stage.
  5. Measure the rectangle (170 × 257 mm, 20 mm margins), circle (160 mm diameter) and triangle (150 × 210 mm). The 6 mm cross marks the centre, 105 mm from the left and 148.5 mm from the top.

The calibration page provides previews and downloads; it does not change machine calibration or connect directly to USB. Transfer G-code to the Mac connected to the plotter. The supplied sender checks the file before sending and requires the plotter to be homed. See the Mac sending instructions for the exact steps. Wait for the sender to report completion, not just that all commands were accepted.

Free writing and Saved pages

Open Free writing from this guide or Capture’s Show help. Enter a writer name and draw with a Pencil or mouse. Save page stores the original strokes in this browser; Download SVG exports the current drawing at 200 × 100 mm. These free-writing pages do not become labelled character samples for Compose.

Saved pages lists your pages newest first and can filter by writer. Select a page, inspect it and choose Open this page to continue. Saving edits creates a new copy. Undo/Redo act on the current draft; new writing or Clear removes redo history. Original point data is preserved when opening and saving pages.

Troubleshooting

I can only review one character or see one blending source

Check the selected writer and group in Review. In Blend a character, choose All saved writers / sets if you used a different name for each capture set. Two or four different included original captures of the same character are required. Saved blends do not count as originals. Refresh originals after importing or reviewing.

The blend cannot be saved or looks distorted

Tap Find compatible sources, or choose samples made with the same stroke order and direction. Check that each source is a different capture and is included in Review. Try two compatible sources first, then four. Dots and crossbars count as separate strokes. Save creates a new sample; it does not replace the sources.

The new controls are missing

Save your current work, then refresh the public website. Use the same browser and device as before. The blending controls now work by dragging the transparent, green-bordered result; Preview size is the remaining display slider. Avoid clearing website data, which would remove saved writing.

Characters are missing from Compose

Check the writer, chosen source type and inclusion settings. Capitals and lowercase are separate characters. Saved blends only requires saved blends for the text you use. My alphabet shows gaps. Capture what is missing, include an existing sample, or select Originals and saved blends.

A backup will not import or my writing seems missing

Use a Handwriting Studio JSON backup, not an SVG or G-code file. Read the import message; conflicts leave existing data unchanged. Check the original browser/device and writer name before assuming data is lost. If browser storage is unavailable, use a regular Safari or Chrome window. Keep a backup before changing browser storage settings.

The GitHub link opens 127.0.0.1 and cannot connect

That address belongs to the older local Mac server. Use the public Handwriting Studio website for the current app. The GitHub repository itself stores the code; GitHub Pages hosts the website.

Current limits

The app supports the characters offered in Capture, plus the listed joined pairs. It does not recognise handwriting, edit individual stroke points or automatically join arbitrary letters. Compose supports up to 20 A4 portrait pages with a separate download for each page. There is no direct USB plotting control in the website, graphical plot queue, automatic cloud sync or installed offline mode. The older Mac server has a smaller feature set; this guide describes the public website.
