Select one character and two or four original samples. Drag the blended character towards a source to make it more like that sample, then save the result as a new sample. Original captures are preserved. Each source must be a different capture of the same character. If your sets use different writer names, choose All saved writers / sets; each source lists its writer name. Compatible originals are selected automatically when you change character, source pool or source count. You can change any source yourself; selecting a sample already used by another source swaps those selections. Capture another set to add more originals.

Drag the transparent, green-bordered blended character left or right for two sources, or in any direction for four. Use a finger, Pencil or mouse; scroll from outside the character. Centre blend restores an equal mix. Arrow keys make 1% adjustments; hold Shift for 10% steps.
