Getting started

The public app runs in Safari or Chrome, including on an iPad. You do not need to start the Mac app or sign in. Writing is saved in this browser on this device; it is not uploaded to GitHub or automatically shared between devices.

  1. Capture a set using the same writer name for the same person. Repeat sets to collect variations.
  2. Review samples to check characters, exclude poor examples or adjust their baseline.
  3. Blend a character to mix two or four captures and save a new version.
  4. My alphabet shows coverage and lets you choose preferred versions.
  5. Compose creates an A4 preview and downloads SVG or plotter G-code.
  6. Use Backup / Import regularly to keep a copy of your saved work.

Capture letters and other characters

  1. Enter a writer name and tap Done. Choose Lowercase, Uppercase, Numbers, Punctuation and symbols, or Joined pairs.
  2. Practice is optional and is not saved. Tap Start capture to open the next unsaved sheet for that writer and capture type.
  3. Write the labelled character inside each box using a Pencil or mouse. Keep every stroke, including dots, in its own box. Fingers operate controls but do not draw on the capture sheet.
  4. Tap Save sheet and wait for confirmation. The next sheet opens only after a successful save. Undo, Redo and Clear sheet affect the current draft.
  5. At the end of the set, review or compose, or choose Capture another set. Two complete sets give two originals per character; four give four.

Each set shuffles its characters. Lowercase has six sheets covering all 26 letters; other groups show their own sheet count. Capture types keep separate progress. Finish the current set before changing type. The writer is fixed during capture; to change writer, save the sheet and reopen Capture.

Keep small letters around the small-letter guide and capitals around the tall-letter guide. For f, g, j, p, q and y, place the body on the baseline and the tail below it. Other lowercase letters settle onto the baseline automatically. Capitals, numbers, punctuation and joined pairs retain their drawn baseline. Write a joined pair as one connected shape.

The five guide checkboxes control Baseline, Small letters, Tall letters, Tails and Shading. Labels and box dividers remain visible. Gentle smoothing changes the displayed and exported line without changing original strokes. A saved sheet resumes correctly after reopening, but an unsaved draft is not restored after refresh.

Review samples

Choose the writer, group and character, then an individual example from the newest-first list. Both original captures and saved blends can be reviewed; blends are labelled.

  • Use this sample in composition includes or excludes that example. Excluded originals are also unavailable as blending sources. Excluding keeps the sample and can be reversed.
  • Baseline shift (mm) moves the character down for positive values or up for negative values, from −10 to +10 mm. It changes placement, not size. The preview is shown at Medium (5 mm).
  • Save changes applies your choices; Reset changes discards pending edits. Save or reset before switching samples.

Baseline adjustments apply at the same physical distance for each Compose writing size. Generate a new Compose preview after reviewing. Changes to an original do not remake an already saved blend; create a new blend if you want it to use different source adjustments.

Blend a character

Blend several captures of the same character. For example, blend two versions of “a”, or four versions of “a”.

  1. Choose Save under writer, the character and Two or Four sources.
  2. If your sets were saved under different writer names, choose Source pool → All saved writers / sets. Each source choice shows its writer, date and sample identifier. This does not merge or rename writers.
  3. Select a different original in each source box. Selecting one already used in another box swaps those selections. Saved blends cannot be selected as source originals.
  4. Drag the green-bordered blended character towards a source to make it more like that source. Its shape updates continuously. With two sources, move left and right between A and B. With four, move in any direction between A/B above and C/D below.
  5. Tap Save blended sample to save the displayed result under the chosen writer. It is then available in Review, My alphabet and Compose. Original captures are kept.

After saving, the confirmation panel shows the character, writer and preview. Use as preferred selects it for that writer. View saved blend opens My alphabet with the saved sample highlighted. Blend next character moves to the next character in the list and restores an equal mix; save first to keep your current result.

Choose a Saved version and tap Reopen source mix to restore its original sources, stored baseline adjustments and blend position. You can also reopen from the sample’s card in My alphabet. Adjusting and saving creates a new version. Later Review adjustments on the saved blend stay with that old sample. If an original source is excluded, include it in Review before reopening. Changing the source selections uses their current Review adjustments.

The draggable result has a transparent background, so source letters remain visible underneath it. Use a finger, Pencil or mouse. Scroll the page from outside the draggable character. Centre blend restores an equal mix: 50% each for two sources, or 25% each for four. At a source position, that source contributes 100%.

Show guides is off by default. Preview size enlarges the display from 100% to 200%; swipe sideways outside the draggable result to inspect an enlarged preview. These display controls do not change the saved blend. With the result focused, arrow keys adjust the mix by 1%; Shift + arrow keys adjust it by 10%. Up/down apply to four-source blending.

Normalisation and compatible samples

The app aligns source left edges and baselines, then compares 64 evenly spaced points along each stroke. It retains your relative letter sizes rather than forcing every letter to the same height. Sources need matching stroke counts, order and direction, and sufficiently similar shapes. For a dotted letter, make the body and dot in the same order in each capture. Incompatible samples cannot be blended; choose another source or capture another example. Inspect the result before saving.

My alphabet and preferred versions

Choose a writer and group to see which characters have included originals, saved blends and preferred versions. The summary lists missing samples and characters without a saved blend.

Select a character, compare its samples, and tap Use as preferred on an included original or blend. Clear preferred version returns that character to normal sample selection. Choices save immediately and belong to the selected writer. An excluded preferred sample is shown as unavailable and is not used.

In Compose, Use preferred versions when available is enabled by default. A preferred version must be included and match the selected source type. If it does, every occurrence of that character uses it; otherwise Compose selects from the allowed samples. Turn the option off to cycle through variations instead.

Alphabet proof sheet

In My alphabet, tap Alphabet proof sheet to test the selected writer and group. Choose originals, saved blends or both, and Small (3 mm), Medium (5 mm) or Large (8 mm). Included preferred versions are used when the source type permits them; otherwise the newest included sample is used.

The available characters appear in group order, followed by an optional test sentence. Missing group characters are listed and omitted from the character row. Missing characters in your test sentence prevent export: capture them, change the source type, edit the sentence or leave it blank. The initial example uses available writing; your edited text is kept when changing settings.

The preview updates as you change size, source, group or sentence. Refresh preview reloads saved choices too. Download A4 SVG and Download plotter G-code export exactly the displayed handwriting to alphabet-proof-a4.svg or alphabet-proof-a4.gcode. Downloads are disabled while updating or when the page does not fit.

The on-screen preview is fitted to the display. Exports use the selected physical size on A4 with 20 mm margins. Print SVG at 100% without fit-to-page. Send G-code from the connected Mac using the verified calibration procedure.

Compose and export

  1. Choose a writer and enter text using characters you have captured. Capitals, digits, supported punctuation, spaces and line breaks are allowed. The initial example uses available characters; your edited text is preserved when settings change.
  2. Choose Original samples only, Saved blends only, or Originals and saved blends. The default includes both. Saved blends only reports missing blends instead of substituting originals.
  3. Choose the sample pool: Latest three per letter (default), Latest four per character, Latest only, or All saved. Repeated characters cycle through that pool, newest first, unless an eligible preferred version is enabled.
  4. Choose Small (3 mm), Medium (5 mm) or Large (8 mm). These sizes refer to the small-letter guide and preserve your natural proportions. Set Gentle smoothing and Use saved joined pairs as desired.
  5. Tap Generate preview, inspect the result, then choose Download A4 SVG or Download plotter G-code. Look in your browser’s Downloads.

When enabled, saved joined pairs replace matching character pairs where available; otherwise individual letters are used. Pair samples follow the same source, inclusion and preferred-version rules. The supported pairs are th, he, in, er, an, re, on, at, en, nd, oo, fi, of and tt. This does not automatically join all letters into cursive.

The page is A4 portrait (210 × 297 mm) with 20 mm margins. Whole words wrap together, with spacing adjusted using neighbouring letter shapes. Text is limited to 2,000 characters and must fit on one page. A word that is too wide or a page that overflows produces a message; use smaller writing or less text.

Letter spacing, Word spacing and Line gap adjust from 50% to 200%. At 100% they use the normal layout. Letter spacing changes the distance between character starts, word spacing changes the space between words, and line gap changes the clearance between lines. Character size and shape stay the same. Tight spacing can overlap letters. Reset spacing returns all three to 100%.

After Generate preview, these spacing controls update the preview live. The previous image stays visible while updating; both downloads remain disabled until the new result is ready. If the new spacing does not fit, reduce it, use smaller writing or shorten the text. Other settings still require Generate preview. Spacing settings apply to the current session and do not change saved samples.

Each pen stroke exports as its own line path. Changing text, settings, saved samples, review choices or preferences invalidates the old preview; generate again before downloading. G-code uses the same preview and the verified calibration described below. The website downloads files; sending them to the plotter is a separate step.

Backup and import

Writing belongs to the browser and device where you saved it. Switching browser or device does not transfer it. Clearing website data or using private browsing can remove it.

  1. Save your current sheet or free-writing page. Unsaved drafts are not included in a backup.
  2. Open Backup / Import and choose Download backup. Keep the JSON file somewhere safe.
  3. To move devices, transfer the JSON file, open this website in the destination browser, choose the file under Backup / Import and tap Import backup.
  4. After import, refresh the sample list or reopen Capture to see the writing.

Backups include original captures, saved blends and their sources, review settings, preferred versions and free-writing pages. Import validates the whole backup before adding anything. Identical records are skipped. A conflicting version of an existing record rejects the whole import without overwriting work. Keep both backups and use a separate browser/profile with no Studio data to inspect the other version; do not clear your current writing to solve a conflict. The file limit is 100 MB.

Calibration and sending to the plotter

The A4 procedure was physically verified on 8 October 2026. Home is at the paper’s top-left corner: positive X goes right and negative Y goes down. Pen up is Z0.5; pen down is Z5. Drawing speed is 900 mm/min.

  1. Place A4 portrait paper on the bed, home the plotter at its top-left corner and raise the pen.
  2. On Calibration, download and run Shapes with pen up to check movement.
  3. Run Pen down, then up; this stage has no X/Y movement.
  4. Run Draw shapes, Add dimensions and Mark page centre on the same fixed sheet. Alternatively, after the movement and pen checks, download the combined drawing stage.
  5. Measure the rectangle (170 × 257 mm, 20 mm margins), circle (160 mm diameter) and triangle (150 × 210 mm). The 6 mm cross marks the centre, 105 mm from the left and 148.5 mm from the top.

The calibration page provides previews and downloads; it does not change machine calibration or connect directly to USB. Transfer G-code to the Mac connected to the plotter. The supplied sender checks the file before sending and requires the plotter to be homed. See the Mac sending instructions for the exact steps. Wait for the sender to report completion, not just that all commands were accepted.

Free writing and Saved pages

Open Free writing from this guide or Capture’s Show help. Enter a writer name and draw with a Pencil or mouse. Save page stores the original strokes in this browser; Download SVG exports the current drawing at 200 × 100 mm. These free-writing pages do not become labelled character samples for Compose.

Saved pages lists your pages newest first and can filter by writer. Select a page, inspect it and choose Open this page to continue. Saving edits creates a new copy. Undo/Redo act on the current draft; new writing or Clear removes redo history. Original point data is preserved when opening and saving pages.

Troubleshooting

I can only review one character or see one blending source

Check the selected writer and group in Review. In Blend a character, choose All saved writers / sets if you used a different name for each capture set. Two or four different included original captures of the same character are required. Saved blends do not count as originals. Refresh originals after importing or reviewing.

The blend cannot be saved or looks distorted

Choose samples made with the same stroke order and direction. Check that each source is a different capture and is included in Review. Try two compatible sources first, then four. Dots and crossbars count as separate strokes. Save creates a new sample; it does not replace the sources.

The new controls are missing

Save your current work, then refresh the public website. Use the same browser and device as before. The blending controls now work by dragging the transparent, green-bordered result; Preview size is the remaining display slider. Avoid clearing website data, which would remove saved writing.

Characters are missing from Compose

Check the writer, chosen source type and inclusion settings. Capitals and lowercase are separate characters. Saved blends only requires saved blends for the text you use. My alphabet shows gaps. Capture what is missing, include an existing sample, or select Originals and saved blends.

A backup will not import or my writing seems missing

Use a Handwriting Studio JSON backup, not an SVG or G-code file. Read the import message; conflicts leave existing data unchanged. Check the original browser/device and writer name before assuming data is lost. If browser storage is unavailable, use a regular Safari or Chrome window. Keep a backup before changing browser storage settings.

The GitHub link opens 127.0.0.1 and cannot connect

That address belongs to the older local Mac server. Use the public Handwriting Studio website for the current app. The GitHub repository itself stores the code; GitHub Pages hosts the website.

Current limits

The app supports the characters offered in Capture, plus the listed joined pairs. It does not recognise handwriting, edit individual stroke points, automatically join arbitrary letters, or generate multiple-page jobs. There is no direct USB plotting control in the website, graphical plot queue, automatic cloud sync or installed offline mode. The older Mac server has a smaller feature set; this guide describes the public website.
